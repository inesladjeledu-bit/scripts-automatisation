# Scripts d'automatisation système

Collection de scripts pour automatiser des tâches d'administration récurrentes.

## Scripts inclus
- `backup.sh` — sauvegarde automatique de répertoires
- `check-disk.ps1` — surveillance de l'espace disque
- `create-users.ps1` — création en masse de comptes utilisateurs Active Directory

## Outils
Bash, PowerShell
